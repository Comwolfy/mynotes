## [Week 1 - Information Storage Before Computers] (https://docs.google.com/presentation/d/1iZOsxzKZx8qhsOrXArxFmZ8gGGxtJgCmp3OSMO0eQ8Y/edit) 
- Writing evolved from ancient systems like Sumerian cuneiform and Egyptian hieroglyphs.
- Early number systems included the Babylonian base-60 system and Roman numerals.
- Gutenberg's printing press (around 1450) lowered book costs and helped spark the Protestant Reformation.
- Typography terms (like uppercase, lowercase, and serif) come from the physical arrangement of old printing presses.
- Early typewriters popularized the QWERTY keyboard layout and monospaced fonts.

## [Week 2 - Representing Text and Numbers in Computers] (https://docs.google.com/presentation/d/1ZtMsPJXCIrFrxau5VNhNpg_BgzF8ITMLNfLcIL12qtE/edit)
- Computers use RAM for short-term working memory and drives (like hard drives or SD cards) for long-term storage.
- A bit (0 or 1) is the smallest unit of data, and 8 bits make a byte.
- Computers rely on binary (base 2) and hexadecimal (base 16) number systems.
- The ASCII standard originally mapped 128 basic characters and codes to numbers.
- Unicode (often using UTF-8) expands on ASCII to support over a million characters for all global languages.

## [Week 3 - Text Structure] (https://docs.google.com/presentation/d/1qahZAC12o-T_O2eYEnz4lDeA-PDAoKro5qFIkeCjRCY/edit)
- Text files use simple structures like lines, spaces, and paragraphs to organize data.
- Markup languages tell computers how to format and display text.
- Markdown is a simple formatting language that uses symbols like `#` for headings and `*` for lists.
- JSON and XML are formats used to store structured data so it is easy for both humans and machines to read.
- Special characters in code must be "escaped" (often using a backslash `\`) so the computer reads them as regular text.

## [Week 4 - Working With Text] (https://docs.google.com/presentation/d/1u0fSAtLD7axf5IAe2K6jokRmLhLiTnMk-nF6wB1GCIk/edit)
- Good posture and touch-typing skills help prevent back pain and repetitive strain injuries.
- Keyboard layouts (like QWERTY or Dvorak) vary by region and use modifier keys (Shift, Ctrl) for shortcuts.
- Text editors (like VS Code or Notepad) are used for editing plain text and code, unlike word processors (like MS Word).
- Wildcards (`*` or `?`) act as placeholders for searching text or file names.
- Regular Expressions (RegEx) offer an advanced way to search for specific text patterns (e.g., `[0-9]` for numbers).

## [Week 5 - Command Line Interfaces] (https://docs.google.com/presentation/d/1imnhF79NJak6mrT3HBVRusLjaFWo_duKI5ys6CdlhCY/edit)
- Command Line Interfaces (CLI) evolved from punch cards to interactive text-based terminals.
- CLIs are still heavily used for precise control, automating tasks, and working remotely.
- CLI commands use standard inputs/outputs, and you can chain commands together using pipes (`|`).
- Basic Unix terminal commands include `ls` (list files), `pwd` (print current directory), and `cd` (change directory).
- SSH allows you to securely control remote servers, while tools like `scp` or `sftp` are used to transfer files.
